
# EduGrade — Academic Assessment Platform

An MCA internship project exploring an academic assessment and smart grading platform using Python and Django.

## Project Overview

EduGrade is a Python/Django-based academic assessment platform with role-based interfaces for students, teachers, and administrators.

The application covers:
- Student, teacher, and administrator dashboards
- Assignment creation and management
- Student submissions and feedback
- AI-assisted assessment workflows
- Academic progress and grading features

## Technologies

- Python
- Django
- HTML
- CSS
- JavaScript
- Database concepts and Django ORM
