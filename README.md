
# EduGrade — Academic Assessment Platform

An MCA internship project exploring academic assessment and grading using Python and Django.

## Project Overview
EduGrade provides role-based interfaces for students, teachers, and administrators. The project covers assignment management, submissions, feedback, and AI-assisted assessment workflows.

## Technologies
- Python and Django
- HTML, CSS, JavaScript
- Relational database concepts

## My Involvement
Participated in mentor-guided project learning, frontend and backend exploration, basic modifications, testing, and project documentation.
